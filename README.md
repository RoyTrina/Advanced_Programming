## Module description 
This module introduces students to more advanced programming constructs and techniques and build on their knowledge from the first two years. This will include a review of Java, Threads and synchronisation, File I/O sockets, client/server, JSON and web services.

## Module aims
To introduce students to more advanced programming constructs and techniques and build on their knowledge from the first two years. This will include a review of Java, Threads and synchronisation, File I/O sockets, client/server, JSON and web services.

### Learning outcomes
By the end of this module, students will be expected to be able to:

1. Demonstrate systematic knowledge and understanding of a number of advanced programming constructs and techniques, such as Functional Interfaces, Unit tests, Concurrency, Type systems, Networking, Generics, and Functional Programming concepts.

2. Demonstrate ability to analyse and apply these constructs and techniques, in the design and synthesis of non-trivial software applications solving non-trivial problems.

3. Demonstrate ability to communicate and critically reflect and evaluate strengths and weaknesses of application design and implementation, both generally as well as in relation to own work, and in the context of the constructs and techniques discussed in the module as well as in terms of good software engineering practices more generally.
